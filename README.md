# Zero Translate privacy policy

This folder is intended to be published as a separate public GitHub repository. It contains the privacy policy only; the extension source stays in its own repository.

## Publish with GitHub Pages

1. Create a public GitHub repository named `zero-translate-privacy`.
2. Upload the files in this folder to that repository.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. When deployment finishes, open the published site and verify it is accessible without signing in.
6. Paste the published HTTPS URL into the Chrome Web Store's **Privacy policy URL** field.

The default site address will be `https://YOUR-USERNAME.github.io/zero-translate-privacy/`. Replace `YOUR-USERNAME` with the account that owns the repository, or use the URL GitHub shows in Pages settings.

`index.html` is the published policy page. It is a standalone, responsive page with no external fonts, scripts or images. `index.md` is the Markdown copy. Keep both files up to date when the extension's data handling changes.
